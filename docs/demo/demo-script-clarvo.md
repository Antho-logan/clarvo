# Clarvo Private Beta Demo Script

## 30-Second Dutch Pitch

Ik bouw Clarvo, een Nederlandse AI-werkruimte voor juridisch onderzoek. De eerste focus ligt op huurrecht en arbeidsrecht. Het systeem geeft geen juridisch advies en vervangt geen advocaat, maar helpt om brononderbouwde antwoorden, contractrisico's en conceptmemo's sneller te maken - altijd met citaties en juristencontrole.

## 5-7 Minute Demo Script

1. Open `clarvo.nl`.
2. Show landing page.
3. Explain private beta positioning.
4. Open login/private demo.
5. Show dashboard.
6. Ask huurrecht question.
7. Show citations.
8. Paste/upload huur clause.
9. Ask review question.
10. Show `[Contract D1.P1]`, risk, recommendation, source trail.
11. Save to Matter.
12. Draft memo.
13. Refusal demo.
14. Close with private beta feedback ask.

## Exact Demo Questions

- "Wat geldt bij opzegging van huur van woonruimte?"
- "Wanneer is ontslag op staande voet geldig?"
- "Wat geldt bij loondoorbetaling tijdens ziekte?"
- "Kun je mijn volledige belastingaangifte doen?"
- "Beoordeel deze bepaling voor een Nederlandse huurovereenkomst. Welke risico's zie je?"

## Demo Clauses

Huur:

```text
Verhuurder mag de huurovereenkomst op elk moment beëindigen met een opzegtermijn van één maand, zonder opgave van reden.
```

Arbeidsrecht:

```text
Werkgever kan de arbeidsovereenkomst per direct beëindigen indien werknemer naar oordeel van werkgever onvoldoende functioneert.
```
