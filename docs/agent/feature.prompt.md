# Feature Prompt

You are implementing a feature.

Follow AGENT_NATIVE.md.

Before coding:
1. Inspect current implementation.
2. Define the feature goal.
3. Define user behavior.
4. Define data/state changes.
5. Define invariants.
6. Identify risks.
7. Create a minimal implementation plan.

Implementation rules:
- Minimal diff.
- Follow existing patterns.
- No new dependencies without approval.
- No mock production behavior.
- Keep code typed and readable.
- Add or update tests where practical.

After coding:
- Run available checks.
- Report changed files.
- Explain how to test.
- Mention risks and what was not verified.
