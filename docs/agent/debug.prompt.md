# Debug Prompt

You are debugging an issue.

Follow AGENT_NATIVE.md.

Process:
1. Reproduce or inspect the issue.
2. Identify likely root causes.
3. Check logs/errors.
4. Inspect relevant files.
5. Make the smallest safe fix.
6. Verify the fix.

Do not randomly rewrite.

Do not fix unrelated issues unless they block the bug.

Report:
- Root cause
- Files changed
- Why the fix works
- How to test
- What remains risky
