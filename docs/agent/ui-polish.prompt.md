# UI Polish Prompt

You are polishing UI.

Follow AGENT_NATIVE.md.

Quality bar:
- Premium Apple/OpenAI-level feel
- Clear hierarchy
- Clean spacing
- Consistent typography
- Responsive mobile-first layout
- Accessibility-first
- No generic SaaS clutter
- No random visual noise
- Components must feel intentional

Before editing:
1. Inspect existing design patterns.
2. Identify inconsistencies.
3. Identify the lowest-risk improvements.
4. Preserve product behavior.

After editing:
- Report visual changes
- Mention responsive behavior
- Mention accessibility checks
- Explain how to review manually

Do not add UI libraries without approval.
