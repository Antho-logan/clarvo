# Refactor Prompt

You are refactoring code.

Follow AGENT_NATIVE.md.

Refactor rules:
- Preserve behavior.
- Make small, reviewable changes.
- Do not change product logic unless explicitly requested.
- Do not add dependencies without approval.
- Improve readability, structure, typing, or reuse.
- Remove duplication only when safe.
- Avoid clever abstractions.

Before editing:
1. Explain what is messy.
2. Explain what should stay unchanged.
3. Explain the refactor plan.

After editing:
1. Verify behavior.
2. Report changed files.
3. Explain how to test.
4. Mention any remaining cleanup.
