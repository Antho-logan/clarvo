# Clarvo Docs

Use this folder as the project memory and operating manual. Keep active docs short and current; move stale research or rejected paths into `docs/archive/`.

## Active State

| Doc | Purpose |
|---|---|
| `CURRENT_STATE_OF_TRUTH.md` | Verified architecture and project state. This wins over older planning docs. |
| `NEXT_PHASE_BRIEF.md` | Current phase and exit criteria. |
| `REMAINING_CODE_WORK.md` | Code-finish closure marker. |
| `PROJECT_MAP.md` | Where source, tests, routes, backend modules, and docs live. |
| `mvp_finish_runbook.md` | Manual MVP acceptance flow. |
| `embedding_lifecycle_runbook.md` | Embedding backfill and lifecycle operations. |

## Operational Reports

| Doc | Purpose |
|---|---|
| `MVP_READINESS_REPORT.md` | Historical readiness snapshot. Verify against the live database before treating it as current. |
| `dashboard_product_qa_report.md` | Dashboard QA notes. |
| `ops_*.md` | Operational snapshots for embeddings, corpus gaps, evals, and citation audit. |

## Planning

| Folder | Purpose |
|---|---|
| `next-phase/` | Corpus, eval, embedding, open-question, and operating-model planning. |
| `agent/` | Agent prompts and project memory for repeatable engineering workflows. |

## Archive

| Folder | Purpose |
|---|---|
| `archive/briefings/` | One-off handoff or briefing documents. |
| `archive/rejected-supabase/` | Supabase research kept for context after the architecture decision rejected that path. |
